# GooseGadgets source workspace

This repository owns the mini-mod source published at HWG90/GooseGadgets. Each mod lives in its named folder. Keep runtime, documentation, tests and builders together there.

Verify Git identity and status before edits. Build into each mod's ignored `dist/releases` directory. Preserve unrelated mods and user changes. Package with explicit file allowlists; do not include installed game files, settings, logs, backups, captured game data or private research.

Treat offline validation, package identity, local installation and observed in-game behavior separately. A release for one gadget does not authorize publishing or deploying another gadget. Installed files and active games require separate deployment authorization.
