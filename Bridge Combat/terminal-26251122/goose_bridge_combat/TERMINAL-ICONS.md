# Weapon terminal artwork

Stratagem symbol reproductions by nvigneux and contributors:
https://github.com/nvigneux/Helldivers-2-Stratagems-icons-svg

Pinned revision: e7b06c68c53f49283b80d0dc3dfb491bd448ad19.
The upstream README explicitly permits use in other projects.
Helldivers 2 game artwork belongs to its respective owners.

The 31 supplied SVGs and their URL/SHA-256 provenance are retained in
bridge-combat/assets/terminal-icons. The offline build_terminal_icons.py
compiler creates cached rectangle masks; no player dependency or network
request is needed. Entrenchment Tool and Break-Action Shotgun use a neutral
equipment mark because this source has no matching stratagem symbol.

The palette follows DBF-MCM's charcoal, brass, gold and ivory workspace theme.
