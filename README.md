# GooseGadgets

A little exhibition of standalone Helldivers 2 mods by Goose. Each gadget has its own folder, source, instructions and release packages.

| Gadget | What it does | Loaders |
| --- | --- | --- |
| [Height Over Bore](Height%20Over%20Bore/README.md) | Restores muzzle-based aiming and follows weapon changes, death, respawn and sessions. | BSL, LLL, MDL |
| [Bridge Combat](Bridge%20Combat/README.md) | Experimental toggle for using equipped loadout on the Super Destroyer bridge. | LLL |

Download packaged mods from [Releases](https://github.com/HWG90/GooseGadgets/releases). Install one loader variant per gadget. Source builds and experimental limits are documented in each folder.

Small mods, one idea at a time.
